## Rules

1. A proposal counts when it is submitted, not when the draft is finished.
2. A demo link counts only if you opened it the same day and it loaded.
3. Do not count Dependabot PRs, README edits, or issue filing as revenue activity.
4. If cash collected is 0 for four straight weeks, stop opening new product repos.
